FRACCIÓN AUTÓNOMA 4.0 - PROTOTIPO FUNCIONAL

Contenido:
- index.html: aplicación principal
- styles.css: diseño visual responsivo
- app.js: navegación, retos, progreso, retroalimentación, autoevaluación y vista docente
- manifest.webmanifest + sw.js: base PWA instalable

Cómo abrir:
1. Descomprima la carpeta.
2. Abra index.html en un navegador moderno.
3. Para instalación como PWA, sírvala desde HTTPS o localhost.

Funciones incluidas:
- Pantalla de inicio con meta y progreso.
- Cuatro secuencias de aprendizaje.
- Comparación 3/4 vs 2/3, como en el diseño del capítulo.
- Pistas, explicaciones, reintento y retroalimentación.
- Autoevaluación metacognitiva.
- Panel de progreso con intentos y ayudas.
- Vista docente demostrativa.
- Persistencia local con localStorage.

Nota técnica:
La "IA" del prototipo funciona de forma simulada/reglada para conservar el flujo pedagógico sin requerir API externa. La integración con una API real puede añadirse después.
